# Aspire to More

Slide deck for **Aspire to More - Smarter Onboarding and Cleaner .NET Development**.

## Contents

- `aspire-to-more-intro.pptx`: 24-slide, approximately 55-minute introductory deck with speaker notes.
- `generate_deck.py`: editable source generator using `python-pptx`.
- `demo/`: compact AppHost and API teaching scaffold.

## Build the deck

```powershell
python generate_deck.py
```

The deck follows the visual language of the supplied Aspire workshop deck, but narrows the content to an introductory talk. The intended pacing is roughly 51 minutes of content and 4 minutes for questions.
