# Aspire intro demo

This is the small demo shape used by the talk. The complete runnable sample is intentionally kept short so the audience can see the application model without wading through business logic.

Suggested live flow:

1. `aspire run`
2. Open the Aspire dashboard URL printed by the CLI.
3. Show `web`, `api`, and `cache` as named resources.
4. Open logs and health for `api`.
5. Change the AppHost reference or API response and rerun.

The source is a teaching scaffold. Use the current Aspire CLI/templates to create the exact project files for the installed SDK version.
